# DOM成果组织规范

> 演示规范数据，非真实行业标准。

本规范说明成果文件、说明材料和检查报告怎样命名、存放及列入清单，方便查找和核对。

## 目录结构

交付目录应分离成果文件、元数据、质量报告和复核记录。
目录名称不得作为产品状态或复核结论的唯一事实来源。
不同用途的材料可以放在不同目录，清单必须写明实际存放位置。
检查时应确认每个目录中的文件属于当前订单和成果版本，排除临时输出、重复材料和其他任务附件。
存在名为“已通过”的目录，只能说明命名方式，不能证明其材料已经复核通过。

## 文件命名

成果文件名应包含稳定任务标识和产品类型，不应包含用户个人信息。
同一交付批次中的文件命名规则必须保持一致。
有多个成果版本时，应在文件名或存放目录中明确区分版本，并在清单中记录准确路径。
文件重命名后需同步清单引用，不能让质量报告仍指向无法找到的旧文件名。
业务归属和完成状态应核对正式任务记录，不能仅根据文件名中出现的任务编号作最终判断。

## 清单要求

交付清单应列出文件路径、类型和完整性校验值。校验值用于核对文件内容是否与登记时一致。
缺少清单项或出现未登记文件时，应阻止生成最终交付包。
核对时要做两遍：按清单逐个找到文件，再检查实际交付的文件是否都已列入清单。
还应核对文件大小、成果版本及校验值是否对应最终文件；文件内容变化后应重新生成相关校验信息。
校验值一致只能支持文件完整性检查，不能单独证明影像质量或复核结论合格。

## 版本要求

重新生产的成果必须形成新版本，不得静默覆盖已进入复核的文件。
新版本应写明来自哪个任务、替代哪个旧版本。旧材料保留用于回查，并标明本次是否继续使用。
提交复核后又替换成果文件时，应重新核对引用该文件的质量报告、元数据和复核材料。
仅修改文件名不能说明成果发生了什么变化，也不能让旧复核结果自动适用于新成果。
