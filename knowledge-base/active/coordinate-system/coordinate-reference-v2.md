# DOM坐标参考要求

> 演示规范数据，非真实行业标准。

坐标参考用于说明影像中的位置怎样对应到实际地理位置。本规范要求成果文件、说明材料和检查报告使用一致的坐标依据。

## 版本声明

本演示版本自2025年1月1日起替代1.0历史版本。
本版本适用期内的新生产任务应使用本版本，不得混用历史要求。
使用前还应核对产品、卫星、处理级别、业务日期，以及查阅人员是否有权限，不能只核对版本号。
回查历史规则时应标明所用版本及适用时间，不能把历史要求直接写成当前处理建议。
有效期和替代关系以规范登记记录为准，文件名中的版本字符只用于辅助定位。

## 坐标信息

DOM成果必须在元数据中声明坐标参考和处理参数版本。
坐标信息缺失、互相矛盾或无法关联当前成果时，应判定为质量异常。

- 写清使用的坐标系统名称或定义，以及需要核对的投影和单位。投影说明怎样把地理位置表示在平面上，单位说明数值按什么计量。
- 发生坐标转换时，记录使用了哪些参数、这些参数来自哪版资料。

需要检查成果内部空间信息与元数据声明是否一致，不能只核对文件名或未经核实的文字说明。
资料缺失时应列出需要补充的项目；不得凭经验指定一个坐标值，再把它写成已经核实的事实。
本演示文档不预设通用坐标参考或转换参数，实际采用值须由项目要求和对应成果证据确定。

## 一致性要求

成果文件、元数据和质量报告中的坐标参考必须一致。
坐标一致性结论应由实际成果、元数据及检查记录共同支持，不能仅根据一处文字说明作出。
按下面顺序核对，并记录在哪一步发现差异：

1. 打开成果文件，查看其内部坐标信息。
2. 对照元数据中的坐标说明，再检查本次处理参数和质量报告。
3. 除名称外，还要核对单位、投影参数和版本；名称相同但参数不同，仍需查清原因。

例如，成果内部定义与元数据声明不一致时，应记录具体不一致项，不能只修改元数据文字掩盖成果问题。

## 复核要求

坐标参考修正后必须重新生成成果并重新提交质量复核。
修正时记录旧成果版本、为什么修改、使用什么参数，以及生成的新成果版本，让复核人员能查清前后变化。
还应检查元数据、质量报告及相关清单是否同步更新，不能只替换成果文件。
需要分别核对新成果是否已经生成、问题是否关闭、复核是否通过；这些要求不能仅凭处理计划认定完成。
