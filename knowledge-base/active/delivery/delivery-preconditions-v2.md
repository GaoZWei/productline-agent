# DOM成果交付前置条件

> 演示规范数据，非真实行业标准。

本规范用于判断当前成果能否交付。生产、问题处理、复核和交付状态必须一起检查。

## 有效版本

本版本自2025年4月1日起生效，并替代1.0历史版本。
本版本适用期内的交付判断必须使用本版本，回查历史事项时应注明当时采用的规则。
使用前应确认规范适用的业务日期和产品范围，并确认查阅人员有权限，不能只看文件名是否较新。
历史条款可以用于解释过去的记录，但不能以其条件较宽松为由替代当前有效要求。

## 必要条件

允许交付必须同时满足以下条件：

1. 生产任务已完成，即COMPLETED。
2. 所有影响交付的质量问题已关闭。
3. 针对当前成果版本的最近一次质量复核已通过。
4. 交付记录没有处于BLOCKED（已阻断）状态。

这些记录必须对应同一订单、任务和当前成果版本。任一项不明确，都不能认定允许交付。
只满足生产完成或问题关闭其中一项，仍需继续核对其他条件。
无法取得关键记录时应标明材料缺失，不得把未取得的复核结果视作通过。
没有取得交付记录，也不能当作“交付未被阻断”。应取得有效记录后再核对其状态。

## 阻断处理

已经确认某项条件不满足时，应登记具体原因和处理要求，暂停交付办理。关键材料缺失时，应说明待核查项，同样不能放行交付。
ORDER-003存在OPEN坐标系问题和PENDING复核，因此不满足交付条件。
固定示例中TASK-003已经COMPLETED（生产完成），但ISSUE-001未关闭，交付为BLOCKED（已阻断），订单停在QUALITY_REVIEW（质量复核阶段）。
应分别指出未关闭问题和待复核两项原因，并建议创建坐标系返工任务、处理后重新提交复核。
不得只修改交付状态绕过问题处理，实际办理应核对该订单的最新正式记录。

## 重新判断

问题处理和复核完成后，应重新核对最新生产、质量、复核和交付记录，再判断是否允许交付。
重新检查要把四项条件全部核对一遍，不能只看刚修改的那一项。
复核针对旧成果版本，或当前又出现新的未关闭问题时，仍不满足本次交付条件。
核查满足条件后，应由有权限的交付办理人员确认交付安排，保留办理记录。
